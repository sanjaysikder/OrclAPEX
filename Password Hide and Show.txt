1. Add below code Password Item (Post Text):
<span id="pwdItem" class="fa fa-eye pw-item-icon" onClick="viewPWD()" aria-hidden="true"></span>

2. Add the following JavaScript code and change the Item: (Page > Function and Global Variable Declaration)

function viewPWD()
{
    var Vpw = document.getElementById('P101_PASSWORD');
    var VsetIcon = document.getElementById('pwdItem');
 
    if (Vpw.type != 'password'){
         Vpw.type='password';
         VsetIcon.className='fa fa-eye pw-item-icon';
    }
    else
    {
        Vpw.type='text';
        VsetIcon.className='fa fa-eye-slash pw-item-icon';
    }
}

3. Add this code to page inline css:

.pw-item-icon {
    float: right;
    margin-left: -30px; 
    margin-top: 11px;
    position: relative;
    z-index: 1;
}
